OAuth2 API Documentation

This page documents the endpoints currently exposed by `server.js`, including OAuth2 grants, OpenID Connect discovery, profile APIs, admin client management, and token audit APIs.

Metadata

MethodPathPurpose
GET/.well-known/openid-configurationOpenID Connect discovery document.
GET/.well-known/oauth-authorization-serverOAuth2 Authorization Server Metadata.
GET/.well-known/jwks.jsonJWKS placeholder. Tokens currently use HS256 with `JWT_SECRET`.

OAuth2 And OIDC Endpoints

MethodPathAccessPurpose
GET/oauth2/authorizePublic/sessionStarts authorization code flow or renders sign-in/register UI.
POST/oauth2/authorizePublicSigns in and continues OAuth authorization.
POST/oauth2/registerPublicRegisters a user and continues OAuth authorization.
POST/oauth2/tokenClient authSupports authorization code, refresh token, and client credentials grants.
GET/oauth2/userinfoBearer tokenReturns OIDC user claims.
POST/oauth2/introspectClient authReturns active state and JWT claims for access tokens issued to the same client.
POST/oauth2/revokeClient authRevokes access or refresh tokens issued to the same client.

Authorization Request

GET /oauth2/authorize?response_type=code&client_id=salesforce-prod&redirect_uri=http://localhost:3146/callback&scope=openid%20profile%20email&state=demo&code_challenge=CODE_CHALLENGE&code_challenge_method=S256

Token Exchange

POST /oauth2/token
Authorization: Basic base64(client_id:client_secret)
Content-Type: application/x-www-form-urlencoded

grant_type=authorization_code&code=AUTHORIZATION_CODE&redirect_uri=http://localhost:3146/callback&code_verifier=CODE_VERIFIER

The token response includes refresh_token only when the authorization request includes the offline_access scope.

Session And Profile APIs

MethodPathPurpose
GET/api/meReturns current session user.
GET/api/profileReturns current session user.
PUT/api/profileUpdates display name, email, avatar, or password.
GET/oauth2/logoutClears the session cookie and redirects to sign-in.

Admin APIs

These endpoints require a signed-in user with `role=admin`. The static `/apps.html` and `/tokens.html` pages are also guarded before `express.static` serves them.

MethodPathPurpose
GET/api/clientsLists OAuth clients.
POST/api/clientsCreates an OAuth client and returns a generated secret when needed.
PUT/api/clients/:idUpdates client name, secret, redirects, scopes, logo, or active state.
DELETE/api/clients/:idDeletes a client.
GET/api/tokensLists issued access tokens for audit.
DELETE/api/tokens/:idDeletes an access token.

Example Flows

Refresh Token Grant

POST /oauth2/token
Authorization: Basic base64(client_id:client_secret)
Content-Type: application/x-www-form-urlencoded

grant_type=refresh_token&refresh_token=REFRESH_TOKEN

Client Credentials Grant

POST /oauth2/token
Authorization: Basic base64(client_id:client_secret)
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials&scope=openid%20profile%20email
