导入用户

支持 CSV 或 JSON 用户数组，兼容旧系统整表导出（自动去 BOM、忽略多余列）。基础表头 username,email,name,password,role；可选列：description、credits、nickname（昵称）、photo（头像）、ip（最后登录 IP）、ischeck（y/n 邮箱验证）、state（1 禁用 / 0 正常，映射封禁）、create_time / update_time（Unix 秒或日期字符串，会保留）、qq_login_openid（自动绑定 QQ）。密码列留空表示未设置密码，用户登录时会引导先验证邮箱再设置密码。

CSV 示例

username,email,name,password,role
zhang.san,zhangsan@example.com,张三,Passw0rd!,user

JSON 示例

[{"username":"zhang.san","email":"zhangsan@example.com","name":"张三","password":"Passw0rd!"}]
