导入用户

支持 CSV 或 JSON 用户数组，兼容旧系统整表导出（自动去 BOM、忽略多余列）。基础表头 username,email,name,password,role；可选列：description、credits、nickname（昵称）、photo（头像）、ip（最后登录 IP）、ischeck（y/n 邮箱验证）、state（1 禁用 / 0 正常，映射封禁）、create_time / update_time（Unix 秒或日期字符串，会保留）、qq_login_openid（自动绑定 QQ）。email 列可留空：只要填写 username 即可导入，系统会使用内部占位地址，该账户邮箱状态记为未绑定，也不会成为可投递邮箱；username 和 email 同时为空才跳过（缺少用户名），填了格式不正确的邮箱则跳过并提示邮箱格式无效。密码列留空表示未设置密码；没有邮箱且没有密码的账户登录时会提示联系管理员重置密码。

CSV 示例

username,email,name,password,role
zhang.san,zhangsan@example.com,张三,Passw0rd!,user

JSON 示例

[{"username":"zhang.san","email":"zhangsan@example.com","name":"张三","password":"Passw0rd!"}]

选择文件后将直接上传文件；编辑粘贴内容会清除已选文件。

文件最大 10 MiB；email 可留空（需填写 username），无邮箱且无密码的账户登录时会提示联系管理员重置密码；用户名或邮箱重复的记录会被跳过并列出原因。
